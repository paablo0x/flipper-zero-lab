# Flipper Zero Lab

My Flipper Zero lab where I test different features, tools and security-related stuff.

This repo is mostly for experimenting, learning and keeping track of things I try with the Flipper Zero.

## What I'm working with

- Flipper Zero
- Momentum firmware
- ESP32 development board
- BLE
- NFC / RFID
- Sub-GHz
- Infrared
- BadUSB
- GPIO

## Projects

### BLE

Experiments with BLE scanning, advertising and ESP32-based projects.

### NFC / RFID

Testing NFC and RFID functionality using my own cards, tags and devices.

### Sub-GHz

Learning how Sub-GHz devices work and testing signals in my own lab environment.

### Infrared

Testing infrared features and devices that I own.

### BadUSB

Testing BadUSB payloads on machines I own for learning and security testing.

### GPIO / ESP32

Experiments with the Flipper GPIO pins and external hardware such as ESP32 boards.

## Why?

I'm interested in cybersecurity, especially offensive security, and I like learning by actually testing things instead of only reading about them.

The Flipper is basically another tool for my lab.

## Disclaimer

Everything here is for learning, research and testing on devices/networks I own or have permission to test.

I don't use these experiments against other people's devices or networks.
